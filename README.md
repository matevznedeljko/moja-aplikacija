## Opis aplikacije

Moje naloge je mobilna aplikacija, namenjena organizaciji vsakodnevnih opravil.

Uporabnik lahko pregleduje svoje naloge, označuje opravljene naloge in spremlja svoj napredek.

## Funkcionalnosti
- Pregled seznama nalog
- Označevanje opravljenih nalog
- Spreminjanje statusa nalog
- Prikaz števila opravljenih nalog
- Prikaz napredka
- Navigacija med zasloni

## Uporabljene tehnologije
- React Native
- Expo
- TypeScript
- Expo Router

## Struktura projekta
- src/app/ – zasloni aplikacije
- src/components/ – ponovno uporabne komponente
- src/theme.ts – skupne barve in slogi
- src/utils/ – pomožne funkcije

## Navodila za zagon

1. Prenesi projekt iz GitHub repozitorija.
2. Odpri projekt v Visual Studio Code.
3. Namesti potrebne pakete:

npm install

4. Zaženi aplikacijo:

npx expo start

5. Skeniraj QR-kodo z aplikacijo Expo Go.
